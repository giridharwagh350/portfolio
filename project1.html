🎨 Art Gallery Management System

The Art Gallery Management System is a full-stack application designed to manage artworks, exhibitions, and users efficiently. It provides an intuitive interface for administrators to control content and maintain secure database operations.

💻 View GitHub

🚀 Key Features

  • Admin dashboard for managing artworks
  • User authentication & secure login
  • Artwork upload and management system
  • Database integration with MySQL
  • Responsive design for better usability

🛠 Technologies Used

Java, MySQL, JDBC, MVC Architecture, HTML, CSS
